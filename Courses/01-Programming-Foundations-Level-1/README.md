# Programming Foundations – Level 1

This folder documents my learning from **Programming Foundations – Level 1**, the first course in the **Programming Fundamentals Roadmap by Dr. Mohammed Abu-Hadhoud**.

The course builds a foundational understanding of computers and how they represent and process data before moving deeper into programming languages and coding. I have completed the roadmap and am now documenting what I learned, course by course, starting with this course.

The notes, explanations, examples, and exercises in this folder are my own learning work. This repository is independent and is not an official course repository.

## What I Learned

The course covers foundational concepts including:

- The difference between data, information, knowledge, and wisdom.
- Computer functions, components, memory, and performance concepts.
- How computers represent data using binary, hexadecimal, and octal number systems.
- Bits, bytes, nibbles, and related memory terminology.
- Number-system conversions and the programmer’s calculator.
- Computer networks and basic network types.
- Programming languages, language levels, and how source code is translated.
- The roles of compilers, interpreters, assemblers, and linkers.
- Variables, constants, operations, and calculation priorities.
- The role of C++ in the programming learning path.
